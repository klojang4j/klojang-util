# Klojang Util

Basic Java language utilities.

## Getting Started

To use _Klojang Util_, add the following dependency to your Maven POM file:

```xml
<dependency>
    <groupId>org.klojang</groupId>
    <artifactId>klojang-util</artifactId>
    <version>24.1.0</version>
</dependency>
```

or Gradle build script:

```
implementation group: 'org.klojang', name: 'klojang-util', version: '24.1.0'
```
